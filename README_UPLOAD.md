## Edit a description later

Open `index.html` and search for the project's name or the comment `Repository: REPOSITORY-NAME`. Edit its title, description, technology tags and details in that article. Update the article's `data-search` text as well, so the search reflects your edit. Commit the changed file to publish the update.

`project-catalog.json` is a reference copy of the descriptions. The website displays the HTML cards in `index.html`; editing the JSON alone does not change the website. The catalogue is a snapshot, not an automatic GitHub feed. Add a new article and update the counts when you add another repository.

`portfolio/` contains the same updated site for your existing `/portfolio/` route. Upload that folder too if you want to keep that address current. The `.html.txt` files are synchronised copies retained from your original archive; GitHub Pages displays `index.html`.

To restore a downloadable CV, put your CV at `assets/cv.pdf`, then change the **Request CV** anchor to `href="assets/cv.pdf"` and its label to **Download CV**. If you use the `/portfolio/` copy, give it the same asset or use the root-relative path `/assets/cv.pdf`.

## Project descriptions

### Shop Assistant & Stock Records

Created for my spaza shop to make daily product recording easier. Records costs, quantities and selling prices, calculates product margins, flags low stock and exports Excel summaries.

Technologies / topics: Python, SQLite, CustomTkinter, Excel.

### Customer Shopping Behaviour Analysis

A guided retail analytics project covering data preparation, customer analysis and dashboard reporting. This repository is my fork of Amlan Mohanty’s learning project.

Technologies / topics: Python, SQL, Power BI.

Original project: https://github.com/amlanmohanty1/customer-trends-data-analysis-SQL-Python-PowerBI

### Mathematics of Finance Study App

An interactive MAT442 revision tool combining finance notes with calculators for interest, annuities, loan repayment and bond pricing. Also includes probability and stochastic-process material.

Technologies / topics: HTML, CSS, JavaScript.

### Spam Detection & Data Science Practice

Explores text classification using TF–IDF, Naive Bayes and logistic regression. Includes message-cleaning notebooks and datasets for introductory data-science exercises.

Technologies / topics: Python, Pandas, Scikit-learn, Jupyter.

### Student Residence Billing Interface

A student-residence interface covering applications, room information and billing details, with separate student and administrator screens. Includes requirements and system-design documents.

Technologies / topics: HTML, CSS, Bootstrap.

### MyStudyApp — Course Notes & Questions

A study platform documented around user accounts, courses, notes and questions. The repository contains a project archive and a guide to setting up the Flask application.

Technologies / topics: Python, Flask, SQLite.

### Sakhelwe — Inventory & Loan Management

An ongoing business-system project for chicken and pig stock, customer loans and monthly cash reporting. The public repository currently documents the business requirements.

Technologies / topics: Inventory, Loans, Business requirements.

### Sikhwama Health — Django Foundation

The initial Django structure for Sikhwama Health, organised into core and health apps. The public models and views are starter files awaiting application features.

Technologies / topics: Python, Django.

### Django Authentication Practice

A practice project exploring registration, sign-in, form handling and Django authentication. Includes page templates and draft authentication views, with further work needed on the flows.

Technologies / topics: Python, Django, SQLite.

### Education Platform Landing Page

A landing-page exercise for an education platform, with a styled welcome section and a registration call to action. Focuses on page layout rather than a complete learning system.

Technologies / topics: HTML, CSS.

### Eswatini Website Practice

An early website exercise centred on Eswatini. The files include a main page, an economy page and a login-page design, exploring navigation, images and Bootstrap layouts.

Technologies / topics: HTML, CSS, Bootstrap.

### Unordered Array List in C++

An array-based list exercise with insert, delete, empty/full checks and data display. Uses separate header, implementation and application files to practise C++ structure.

Technologies / topics: C++, Arrays.

### Finance Study App — Alternate Version

Another version of the MAT442 mathematics-of-finance study app, bringing together revision content, interest calculations, amortisation and bond-pricing examples.
